Aquí tienes el resumen rápido para levantar el proyecto en GitHub Codespaces:  Opción Rápida (Todo con Docker en el Codespace)Levantar servicios: Ejecuta en la terminal:
docker compose up -d --build  Cargar datos iniciales: Una vez que los contenedores estén arriba, ejecuta:
docker compose exec backend npm run seed:run  Acceder a la web: Ve a la pestaña "PUERTOS" de tu Codespace, busca el puerto 8080 y haz clic en el ícono del mundo para abrirlo en el navegador.  Opción Desarrollo (Infraestructura Docker + Código local)Levantar solo la infraestructura:docker compose up -d postgres redis minio  Correr el Backend:cd backend $\rightarrow$ npm install $\rightarrow$ npm run start:dev  Correr el Frontend (Web):cd frontend $\rightarrow$ npm install $\rightarrow$ npm run dev  (Asegúrate de configurar VITE_API_URL en frontend/.env apuntando a http://localhost:3000/api/v1)  Correr Mobile (Expo):cd mobile $\rightarrow$ npm install $\rightarrow$ npm run start  
Nota importante para mobile en Codespaces: Como localhost no funciona desde tu celular, cambia la variable EXPO_PUBLIC_API_URL en mobile/.env por la URL pública del puerto 3000 de tu Codespace (ej. [https://tu-codespace-3000.app.github.dev/api/v1](https://tu-codespace-3000.app.github.dev/api/v1)) y reinicia el comando.  Para bajar todo el entorno: docker compose down (agrega -v si quieres borrar los datos de Postgres y MinIO).
